# Project directory

Use C:\decision as the project root for this decision-model work.
The benchmark lives in C:\decision\decision-benchmark; run its commands from that directory.
The initial single-model demo is C:\decision\decision_demo.py.
Put new project files and results under C:\decision, not in the former generated chat workspace.
Read decision-benchmark\README.md for commands and evaluation methodology.
Never print API keys or include .env in result packages.
Mock reports are demonstrations and must not be presented as real model evaluations.
